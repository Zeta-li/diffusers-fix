# 独立 Val16：冻结校准后闭环质量与净延迟验证协议

本轮响应“在 H800 上跑独立 Val16，对比 F/R2/PRIOR/A/B”的请求。实验在 zeta 的 `/workspace/diffusers-fix/research/val16_calibration_validation_20261023` 执行；本目录保存同步副本、原始日志、分析脚本、数据和图表。协议在查看本轮生成结果前确定。结果和失败案例另写 `02_独立验证实测报告.md`。

## 1 研究问题和冻结条件

本轮检验：Train8 得到的校准统计量是否能在未用于拟合的 16 张源图上改善固定局部缓存执行器，并保留至少 10% 的端到端节时。不给 Val16 收集校准标签，不重新选择超参数、编辑区域或阈值，不启动主模型梯度训练或强化学习；Test64 不生成、不调参。

底座为原版 Qwen-Image-Edit，固定修订 `ac7f9318f633fc4b5778c59367c8128225f1e3de`。使用原版对应的 8 步 Lightning V1.0 BF16 LoRA，融合并卸载适配器，CFG=1、8 步、batch=1、native SDPA、VAE tiling。LoRA SHA256 为 `36ee4ff860856559b9c581eaa69414900488f3de8be2f2448586daec77e201b9`。不量化、不 offload、不 compile。

校准文件仅来自上一阶段 Train8：`calibration_train8.npz`，SHA256 为 `6df60e49ca8d618c5458063a80ce5bf3a5b02b0c28c7e618b04b76733964518f`。A 使用 anchor=0 的 img_norm1 均值和总体方差；B 使用六个局部步相对于真实 anchor=0 的逐通道原始 Value 仿射系数。B 的 eta=0.01 由 Train8 的源图级留一法选出，此轮固定。未观测时间对使用恒等映射。主模型参数不更新。

## 2 独立数据与区域

数据为 osunlp/MagicBrush，固定修订 `6c254560879df7851233ea0fd2ae2a62764d0ef2`。沿用已冻结的官方 dev 首轮编辑 16 个源图及排序；分组单位为规范化 COCO img_id。与官方 train 的 Train8、旧三张开发图核对原始/RGB SHA256 和图像哈希，并检查 Val16 内部重复。不得按生成质量替换样本。源码和审计范围请求仅取 source_img、mask_img 与元数据；不读取 target_img 列或 Test 媒体。

沿用已验证的 alpha 掩码解码：RGBA 的 alpha<255 作为保守编辑正区，alpha=0 提供明确可编辑证据。源图与掩码宽高比须满足冻结容差；不猜测裁剪关系。目标约 1MP，宽高按 Qwen 帮助函数取 32 的倍数。把正区外包框映射到目标 16px token 网格，向外取整得到 R0；R0 加裁剪后的两格 halo 得到执行区域 R2。首尾两步全量，其余六步仅更新 R2 目标 token；条件图和文本保持全量计算。

评价区域对五种配置相同，并在生成前保存：core=R0；band(r)=dilate(R0,r)∩dilate(~R0,r)，r=1/2/4；far=~R2。远背景定义针对本轮标注框，与旧三图的人工 allowed-box 指标不可直接合并。区域面积、边界裁剪和源掩码均留档。此为标注辅助的执行器验证，尚不包括自动语义检测、分割或动态扩边的推理开销。

## 3 五种对照

| 配置 | 执行 | 缓存 Value 读取 |
|---|---|---|
| F | 原生全量 8 步 | 无局部缓存近似 |
| R2 | 首尾全量，中间固定 R2 | 原始缓存，不校正 |
| PRIOR | 与 R2 相同 | 通道解析校正，均值=0、方差=1 |
| A | 与 R2 相同 | 同一解析校正，统计量换成冻结 Train8 矩 |
| B | 与 R2 相同 | 冻结 Train8 直接拟合的原始 Value 仿射校正 |

校正只作用于临时读取值，不把预测值写回缓存，不更新真实时间戳。已刷新 token 的时间对为对角恒等映射。K 缓存、目标隐藏状态和 velocity 仍可能陈旧，不能把 Value 校正解释为完整上下文恢复。

四个独立执行器在安装分派器前构造，共用未包装的原生 forward。每请求独立 begin/clear，全部缓存为空才允许下一请求。三套校正表在冷启动时分别构造、常驻，记录秒数和字节数；F/R2 同样保留这些共同静态表以维持运行环境。表不在配置间覆写。B 的权重签名和精确时间检查属于实际部署路径，其开销计入净延迟。

## 4 实际请求计划及计时

16×5 个组合各预热 1 次、测量 3 次，共 **320 次请求、2560 次真实 DiT forward**；本轮不包含额外密集教师/影子调用。先运行全部预热，再按 repeat→case→配置循环测量；每个 case/repeat 的配置顺序按 `(repeat+case_index) mod 5` 轮换。完整 run_id 列表保存在 preregistration.json。出现异常须保留失败记录和实际已调用次数，修复后明确续跑，不能删除失败重算为零。

每源图使用固定种子 2026102201 生成显式 BF16 初始 latent；五配置及重复使用同一张量的 clone。每请求重置 scheduler、generator 和缓存。scheduler 的 raw timestep 先转 BF16 再除以 1000，实际输入为 `[1, 0.95703125, 0.8984375, 0.83203125, 0.75390625, 0.64453125, 0.5, 0.30078125]`。每种配置采集八个极小时间张量，在计时结束后核验，无额外 DiT。

端到端计时从内存源图和已给定 ROI 到 PIL 输出，含 executor begin/索引复制、文本编码、VAE 编码、全部 DiT、校正读取及运行时检查、Euler 更新、解码和缓存清理。源文件 I/O、模型装载、标注获取、静态校正表构造、初始 latent 创建、PNG 保存和指标不计入；分别报告冷启动成本。**不得从测量结果扣除校正开销**。分组件 CUDA event 仅作瓶颈解释，不相加充当墙钟总延迟。

每个源图/配置分别报告三次墙钟中位数、CV，以及相同 case/repeat 相对于 F 的配对耗时比。先对每源图三次比值取几何均值，再按源图汇总和 bootstrap（seed=2026102304，10000 次），避免把 48 次测量冒充 48 张独立图。输出 SHA 核对预热与三次测量的确定性；若不同保留全部不同文件并说明。

## 5 质量、失败及判断

质量只使用 measurement repeat0 的 80 张输出。采用已有 LPIPS Alex spatial=True、normalize=True 的全 RGB 空间图均值，同时报告 PSNR/SSIM/MAE、公共 band2、core 和远背景。候选相对 F 的全图 LPIPS≤0.02，且 extraBG≤1/255 为逐例数值门槛；extraBG=MAE(候选,源图,far)−MAE(F,源图,far)。负值不证明编辑更正确。

逐例非盲视觉检查指令完成、对象/身份保持、文字错误、漏改、粘连、亮度块、边界接缝及区域外变化。F 自身失败单独标记，仍保留全部 16 个源图，不后验过滤。接近 F 不等于完成指令，数值通过不能代替语义评价。人工检查不是独立盲评或用户研究。

报告每个配置的数值通过数、至少 10% 净节时数及二者交集；语义和边界结论另列。独立 Val16 仅提供方向筛查证据，不宣称无损、统计非劣效或正式 Test 泛化。即使 B 的缓存代理误差改善，也必须以闭环图像和净耗时决定是否继续。所有失败、基线失败和方法退化均写入报告，不挑最好结果代替冻结配置。
