# 面向实际收益的双路径预算蒸馏局部编辑方案

日期：2026-10-30。工作名：Budget-Edit。基座：原版 Qwen-Image-Edit＋对应 8 步 Lightning。平台：H800 单卡。本文是新的算法与实验设计，新增 GPU 实验、训练和 RL 均为 0；已有结果见[报告11](11_诊断性净延迟与等预算时机实验.md)。

## 1. 决定：改变主要计算路径，直接优化质量与耗时

主方案是：**全图锚点刷新＋局部大模型计算＋外围小网络预测＋缓存感知蒸馏＋预算策略学习。** 保留八次采样更新，首先降低每次更新的代价。研究重点从“几百参数的头能否比 FIX32 少一点像素误差”改为“经过训练后，多少大模型计算可以由缓存和小网络替代”。

新目标接受可控的近似误差。第一阶段争取相对同引擎完整八步模型减少 **25%–35% 端到端耗时，即约 1.33–1.54×**；工程优化叠加后的整体产品目标为相对现有 6.99 秒参考达到 **1.5–2.0×**。这些是设计目标，实际结果由后续测量填写。

旧实验的失败结论原样保留，新实验采用新的质量—延迟评价协议。完整 F 本身出错的样例继续计入任务成功率，但不要求先修复所有基座错误才能研究加速；另外统计加速器新增的错误和修复的错误。图像与 F 有像素差异本身不再构成停止训练或停止计时的理由。

## 2. 已有证据如何支持这次调整

|实测事实|对新方案的直接含义|
|---|---|
|F 6.9884 秒；FIX32 6.3643 秒，1.0981×|已证明能省时间，但现有路径省得不够|
|DiT 3.6294→2.9843 秒；VAE 编码约 1.134 秒、解码约 1.797 秒|应同时处理 DiT 与编解码开销|
|目标 token 更新比例 53.43%，实际联合 Q 行比例仍有 80.15%|只减少目标图计算没有覆盖主要冗余|
|源码每一步重新计算全部条件图与文本的 Q/K/V、attention 输出和 MLP|条件流缓存是明确可实现的下一刀|
|旧四边头、固定 NEAR 动作头未形成稳定泛化收益|不能继续只增加同一个小动作空间的训练轮数|
|等预算时机全8源的事后最优仅比最佳固定策略改善 MAE 2.10%|该信号适合作辅助，不能承担主要速度贡献|

本方案复用现有执行器、真实缓存、Euler 合同、配对计时和样例账本，替换主要近似路径及学习目标。

## 3. 算法定义

### 3.1 三类 token 与两条计算路径

目标图 token 为 \(X\)，原图条件 token 为 \(S\)，文本／多模态条件 token 为 \(P\)。活动目标位置为 \(A_t\)，其余为 \(U_t\)。活动区是计算索引，不是图像融合 mask。始终更新整个目标 latent：

\[
z_{t+1}=z_t+\Delta\sigma_t\widetilde v_t,\qquad
\Delta\sigma_t=\sigma_{t+1}-\sigma_t.
\]

一条路径用原 DiT 计算重要目标区域，另一条路径用低维空间网络估计外围速度；原图和文本的深层上下文由最近一次全图锚点提供。

~~~mermaid
flowchart TD
    A[源图、指令、可选粗框、初始噪声] --> B[前两步全图 DiT：初始化每层 KV 与速度缓存]
    B --> C[选择预算档与下一次全图刷新位置]
    C --> D{本步为全图锚点？}
    D -->|是| E[全目标＋原图条件＋文本更新，刷新全部缓存]
    D -->|否| F[局部 DiT：活动目标 Q 读取全局 KV]
    D -->|否| G[小空间网络：预测外围 velocity 残差]
    F --> H[组装全图 velocity]
    G --> H
    E --> I[完整目标 latent 执行 Euler 更新]
    H --> I
    I --> J{八步完成？}
    J -->|否| C
    J -->|是| K[完整 VAE 解码，输出图像]
~~~

### 3.2 全图锚点

锚点使用全部 \(X,S,P\)，逐层更新 K/V 和目标 velocity。缓存带有独立时间戳：原图与文本最近锚点、各目标位置最近实算步。锚点后的学生轨迹和教师轨迹可以不同。

缓存的条件流不是数学上不变的常量：原模型是联合注意力，源图输入固定也不代表其深层状态在不同采样步完全一致。因此本方案显式训练模型适应这种近似。

### 3.3 局部步骤：进一步省掉条件图与文本分支

第 \(\ell\) 层只对活动目标生成新鲜 Q/K/V。更新活动位置缓存后，计算：

\[
Q^\ell=Q^\ell_{A_t},\quad
K^\ell=[K^\ell_{A_t},\bar K^\ell_{U_t},\bar K^\ell_S,\bar K^\ell_P],
\]
\[
V^\ell=[V^\ell_{A_t},\bar V^\ell_{U_t},\bar V^\ell_S,\bar V^\ell_P],
\quad
H^\ell_{A_t}=\operatorname{softmax}(Q^\ell(K^\ell)^\top/\sqrt d)V^\ell.
\]

位置编码、有效文本 padding mask 和 token 顺序必须与缓存一致。实现中可用固定顺序的完整缓存缓冲区，不必按上式顺序重新拼接。局部步跳过 \(U_t,S,P\) 的 Q 投影、attention 输出和 MLP；源图／文本的 K/V 也直接读取缓存。所有活动目标仍可注意到全图信息。

相比当前执行器：

|部分|当前 FIX32|新方案局部步|
|---|---|---|
|活动目标|重新计算|重新计算，加入训练适配|
|外围目标 Q / MLP|跳过|跳过|
|外围目标 K/V|历史缓存|历史缓存|
|原图条件 Q/K/V / MLP|每步完整重算|锚点刷新，其余缓存|
|文本 Q/K/V / MLP|每步完整重算|锚点刷新，其余缓存|
|外围 velocity|沿用历史新鲜预测|历史预测＋轻量空间残差|
|外围 latent|继续 Euler 更新|继续 Euler 更新|
|源图像素覆盖目标图|无|无|

实现时保留“仅缓存条件图、文本仍新鲜”的消融臂，量化文本冻结的额外代价与收益。它也是完整缓存质量不足时可以直接使用的中间档，不需要重做全部训练框架。

### 3.4 外围小网络：更新状态而不运行完整 DiT

对未活动位置：

\[
\widetilde v_{t,i}=\bar v_i+
g_\phi(z_t,z_{\rm src},\bar v,\Delta\bar v,
        a_t,d_{\rm ROI},\sigma_t,c_{\rm text})_i,\quad i\in U_t.
\]

活动位置使用当前 DiT 输出。这里 \(\bar v_i\) 始终保存该位置最近一次真实 DiT 的预测；小网络预测不会写回“新鲜缓存”，避免递归把自己的估计当作真实刷新。 \(\Delta\bar v_i\) 来自最近两次真实刷新；只有一次时取零并附可用性标记。

首版网络在打包后的 64×64 token 网格运行：输入投影到 128 通道，四个深度可分离 3×3 卷积残差块，输出 64 维 velocity 修正；时间、预算和池化文本特征通过 FiLM 调制。目标参数量约 0.5–2M，精确数量在实现后记录。末层零初始化，起点退化为旧速度复用。空间卷积让网络看到边界附近的变化，不再局限于逐 token 仿射校正。

它不替代编辑对象的主要生成能力。关键编辑内容由活动 DiT 负责；小网络负责更便宜地更新外围运动趋势、细节和边界。实际总开销目标为单请求时间的 3% 以下。

### 3.5 在 DiT 内部训练缓存适配，减轻活动区误差

在 60 层 attention 输出投影插入 rank-8 LoRA；每五层再对图像 MLP 输出投影插入 rank-8 LoRA。若隐藏宽度为 3072、MLP 宽度为 12288，则约为：

\[
60(2\cdot3072\cdot8)+12((12288+3072)\cdot8)
=4{,}423{,}680
\]

个参数；实施时以实际配置核算。增加共享小 MLP，把时间、原图缓存年龄、外围年龄统计和预算档映射为原时间嵌入的残差。该输出也零初始化。

这样可以在 attention 之后、后续层传播之前补偿过时上下文，而不是把所有压力留给终端 velocity 小头。Q/K/V 权重虽可先冻结，其输入仍会受到前面层的适配影响。

训练时原 Lightning 权重固定，新增 LoRA 可开关；教师和学生共享一份冻结主干，教师关闭新增适配。导出时将新增 LoRA 合并进一份学生权重，避免推理阶段额外的小矩阵调用。合并后的全图锚点也使用学生权重，不能称其与原教师逐位相同。因此另设完整学生八步 \(F_S\) 对照，分离权重变化与稀疏执行的影响。合并前后允许 BF16 舍入差异，并须做输出差异验证。

### 3.6 计算区域与预算档

开始实现时保留 FIX32 核心作为稳定起点，不重新训练四边框头。活动预算按 2×2 token 小块分配，并向可运行的 token 桶取整。核心优先，其余预算分配给边界邻域和少量轮转探针；首版使用冻结规则，随后策略利用小网络特征调度。

目标预算为 25%、50%、75%、100% 四档。若 FIX32 核心超过某档，就提升到容得下核心的档位，记录实际比例；不裁掉核心来制造固定低预算。默认从额外预算中保留 1/8 作域外探针。若额外预算为零则不另加探针。新对象可超出旧框，锚点全图刷新和外围更新提供生长通道；这个机制有助于发现漏算，但不构成覆盖新轮廓的保证。

首版固定三档，步号为 1–8：

|档位|全图锚点|其他步目标活动比例|用途|
|---|---|---|---|
|C：质量档|1、2、5、8|50%，必要时上调|较频繁刷新|
|B：均衡档|1、2、8|25%，必要时上调|主要训练及部署候选|
|S：速度档|1、2|25%，必要时上调|训练承担更强近似，末步也局部执行|

八次 Euler 更新不变。速度档取消的是后续完整重算，并未跳过整个采样更新。训练时覆盖三个档位，最终比较各档完整生成结果。RL 后续可以在第 2 步结束后选档、第 5 步前调整一次预算／刷新。

## 4. 为什么有比当前更大的收益空间

设目标和原图各 \(N=4096\) token，条件文本为 \(M\)。全图步的 Q 行数为 \(2N+M\)。全部上下文缓存后，局部步仅需 \(pN\) 行：

\[
r_Q=\frac{k}{8}+\left(1-\frac{k}{8}\right)\frac{pN}{2N+M}.
\]

以 **示例** \(M=1536\)、核心未超预算为例，C/B/S 的平均 Q 行比例约为 60.5%／44.1%／32.9%，当前 FIX32 实测为 80.15%。这表示减少了哪些矩阵行，不能直接当作耗时比例：K/V 读取仍在，attention、索引、写缓存、投影和 MLP 的比例也不同。

全三流 BF16 原始 K/V 缓存的示例成本为：

\[
2 L(2N+M)d\cdot 2\ {\rm bytes},
\]

取 \(L=60,d=3072\) 时约 6.68 GiB，比当前仅目标 KV 多约 3.87 GiB。推理已有约 57.65 GiB 峰值，但训练激活、反向和非分块 VAE 的显存仍须实测。首版只保留一代逐层 K/V，速度历史只保留两代低维张量，避免双份深层缓存。

用现有时延作 Amdahl 情景分析：

\[
T_{\rm new}\approx T_{\rm DiT}\,r_D+T_{\rm rest}'+T_{\rm small},
\quad T_{\rm DiT}=3.6294,\quad
T_{\rm rest}\approx6.9884-3.6294=3.3590.
\]

这里的残余项由总体与 DiT 汇总差值得到，是设计近似；并非声称各 CUDA 区间与墙钟可严格相加。令小网络及控制开销为假设值 0.05 秒：

|情景假设|预计总秒数|相对现有 F|相对同优化 F|
|---|---:|---:|---:|
|DiT 保留 55%，其余不变|5.405|1.293×|1.293×|
|DiT 保留 45%，其余不变|5.042|1.386×|1.386×|
|DiT 保留 35%，其余不变|4.679|1.493×|1.493×|
|DiT 保留 45%，公共部分降至 2.2 秒|3.883|1.800×|1.501×|

**整张表是预算情景，不是新测速。** 第四行情景中的同优化完整 F 为 \(3.6294+2.2=5.8294\) 秒，不能把 VAE 的共享优化全部归功于局部算法。

工程第一项是检验现有 VAE tiling 是否带来可避免的开销：在显存允许时比较完整／较大 tile 的编解码，验证输出和峰值；随后对固定尺寸 VAE 与计算桶尝试编译。所有公共优化同时应用到完整 F、FIX32 和新方法。冷启动编译时间单列；稳态单请求仍包括输入处理、prompt 编码、源图 VAE、完整采样和解码。交互场景的重复源图编码缓存可另报，不代替单次请求指标。

## 5. 训练方式

### 5.1 数据与样本规模

主实验拟使用 256 个训练来源、32 个校准来源、32 个新开发来源，现有 Test64 保持封存。64／128／256 个训练来源形成学习曲线，若仍有清楚的上升趋势，再扩到 512。每个训练来源先用两个噪声种子。来源、近重复图片与连续编辑链按组划分，不能把同源换指令算独立验证。

任务包含局部属性修改、对象替换、轮廓扩张、接触／遮挡变化四类。排除全局风格或光照作为主任务，但保留扩张压力组。已有看过的样例只能作为训练或开发分析；新 Dev32 和 Test64 不参与拟合。数据 ID 尚未生成和冻结，当前数字是采集目标。

### 5.2 同状态教师与短闭环蒸馏

教师是原始完整八步 Lightning 模型。训练采样学生自己到达的 \(z_t^S\)，查询：

\[
v_t^T=F_{\rm teacher}(z_t^S,S,P,\sigma_t).
\]

逐组归一化速度损失：

\[
\mathcal L_v=\sum_{G\in\{A,B,U\}}w_G
\operatorname{mean}_{i\in G}
\operatorname{Huber}\!\left(
\frac{\widetilde v_{t,i}-v^T_{t,i}}{s_G+\epsilon}
\right).
\]

\(B\) 是活动／非活动边界带；实现时用互斥的活动内区、边界带、外围远区，避免重复计权。\(s_G\) 从训练集冻结为尺度常数；首版 \(w_A,w_B,w_U=(1,2,1)\)，不让背景像素数量淹没对象与边界。

25% 的训练窗口再展开两步，以同一学生起点分别运行学生和完整教师两步，使用：

\[
\mathcal L_{\rm roll}=
\frac{\|z^S_{t+2}-\operatorname{sg}(z^T_{t+2})\|_1}{s_z+\epsilon}.
\]

两步分叉后的教师第二步在教师轨迹上计算；其标签不冒充学生第二步的“同状态”速度。单步速度监督只用于共同起点。其余 75% 用单步窗口控制成本。

对晚期窗口加入边界项：

\[
\mathcal L_{\rm edge}=
\|\nabla_B(\hat z^S_0-\operatorname{sg}(\hat z^T_0))\|_1,\qquad
\hat z_0=z_t-\sigma_t v_t.
\]

边界带用于加权误差，不覆盖或裁切图像。必要时在少量晚期窗口解码，增加训练目标图的局部感知／指令一致性项；该项单独消融和计费。首版采用：

\[
\mathcal L=\mathcal L_v+0.5\mathcal L_{\rm roll}
+0.1\mathcal L_{\rm edge}+0.1\mathcal L_{\rm full}.
\]

\(\mathcal L_{\rm full}\) 为完整学生与教师的速度保持项，用于约束合并 LoRA 后的全图锚点。损失先作训练集尺度归一化。单步 Euler 误差等于速度误差乘 \(\Delta\sigma_t\)，不能把二者当成两个独立学习证据；本方案用真正的两步分叉损失检验误差累积。

### 5.3 单卡实施

冻结主干和 Lightning；训练约数百万适配参数及小空间网络。BF16，batch=1，梯度累积4，激活检查点，首版1000次优化更新；建议学习率 LoRA \(10^{-4}\)、小网络 \(3\cdot10^{-4}\)，梯度裁剪1.0，实际超参在首次训练前冻结。

教师通过关闭新增适配调用同一份冻结主干，不在显存放两份20B模型。教师必须走无状态完整 forward，不能读取或改写学生缓存；原 Lightning 始终启用。逐层 K/V 不落盘成大规模训练数据；每个微批从噪声重建学生前缀并原地建立缓存，缓存在训练窗口入口 detach。窗口内凡被 autograd 使用的缓存视图不能再原地覆盖，应采用独立更新缓冲或延迟提交。重建前缀和同状态教师全部计入实际前向账本。

训练分三段：先暖启动外围网络和 LoRA；随后在学生自身轨迹上联合训练；最后冻结学生进行预算策略学习。每200次更新用固定 Cal32 检查闭环质量与档位速度曲线，不用新 Dev32 反复选择 checkpoint。先跑100微批测显存、迭代时间和数值稳定性，再估计整个训练用时；首个训练阶段安排1–2个单卡工作日，属于资源排期。

## 6. RL 的具体位置

RL 学“本张图该用多少大模型计算、什么时候全图刷新”。首版决策仅两次：第2步结束与第5步开始前。小策略网络读池化的当前 latent／小网络特征、核心比例、预算、缓存年龄、提示词特征。动作包括选 C/B/S 档，以及中途保留、增加目标预算或执行一次全图刷新。

阶段一用训练来源的固定档结果训练代价与质量预测器，得到监督策略。阶段二冻结生成学生，用512条真实完整轨迹做 PPO；每个 episode 都真实生成八步，计入4096次 DiT 前向。若第二次决策要求刷新，它替换该步局部调用，不额外插入一个不记账的 DiT。需要更多 rollout 时用新账本扩展。

首版奖励：

\[
R=Q_{\rm task}
-\lambda\,T_{\rm e2e}/T_F
-2\,\mathbb 1[\text{新增严重结构错误}],
\]
\[
Q_{\rm task}=0.5Q_{\rm edit}+0.3Q_{\rm preserve}+0.2Q_{\rm natural}.
\]

各质量分量固定在 \([0,1]\)：编辑完成以指令／目标对象判断，保持程度对照源图中应保留对象，自然程度评价边界和整体视觉。训练可用冻结自动评价器，留一部分人工配对审阅校准其偏差；评价器版本及额外耗时另记。先在 Cal32 选择 \(\lambda\in\{0.1,0.2,0.4\}\)，生成 Pareto 曲线。策略不能看完整教师未来输出。

实测延迟易受波动影响，训练时可用已配对计时标定的档位成本表；最终必须用真实完整延迟验证。RL 与最佳固定档、相同数据的监督策略比较。若 RL 学成同一档，固定档仍可作为有收益的算法交付，RL 增量据实写零。

这次不再要求先把所有样例做到像素无损才训练策略；它的作用就是在多个不同成本且可用的计算路径之间寻找更好的总体取舍。

## 7. 对照与验收

至少保留：原 F、同引擎优化 F、优化 FIX32、仅条件图缓存、全上下文缓存、外围网络、LoRA＋外围网络、监督预算策略、RL 策略，以及完整学生 \(F_S\)。前三个是基础参考；其余按增量消融，避免把全部组合收益归因于单个头。

主要评价端到端延迟、任务完成率、保持率、配对偏好、严重新增错误。LPIPS／DISTS／像素 MAE 是辅助距离，不再用“MAE必须比FIX32改善2%”作为总开关。新候选都可以测质量和计时，由完整 Pareto 曲线选择运行点。

建议的首个实用运行点：相对同优化完整 F 节时至少25%，任务完成率的点估计下降不超过5个百分点，配对整体质量平均下降不超过0.03（归一化到0–1）。这是新协议的工程目标，不是统计非劣性结论；一并报告来源级区间和逐例结果。小试8/16来源只用于调试，正式结论使用新 Dev32 与封存 Test64；无法达到窄置信区间时扩大评估，而不把少量样本的点估计写成保证。

所有全图刷新、预算上调和持续完整执行计入平均时间；快样例与慢样例共同入表。基座自身错误、加速新增错误、加速修复三者单列。当前 F 的5/8严格通过记录保留。

## 8. 与已有方法的关系及论文贡献定位

|方法|已知核心|本方案拟研究的增量|
|---|---|---|
|RegionE|训练自由的区域生成、全局缓存与速度缓存处理|面向8步蒸馏模型训练完整稀疏学生，并以真实请求代价选择预算|
|SpotEdit|局部 Q、条件图与非编辑区域缓存、感知选区和特征融合|保留全 latent 自由演化；外围由空间网络预测；训练内部适配及预算策略|
|LinCa|可学习可逆分解与不同阶数的特征预测，已含 Qwen-Image-Edit 实现|按编辑任务划分“大模型活动区／小网络外围”并训练闭环学生，联合学习区域与刷新代价|

局部 Q、条件缓存、训练缓存预测都已有先例，不能独立列为首创。论文应验证：**训练后的双路径执行，在相同8步基座和相同工程优化下，是否给出更好的质量—实际延迟曲线；预算策略是否还有额外收益。** 这是当前明确的贡献假设。

特别注意：SpotEdit 原论文已经跳过条件图计算，当前 FIX32 并未完整包含这一点；因此补上条件缓存既是合理工程推进，也是把强对照做扎实。LinCa 官方仓库说明其首页多倍加速数值主要为相对原始完整步数的 FLOPs 比值，不能搬来当本项目8步模型的端到端预期。

2. [SpotEdit: Selective Region Editing in Diffusion Transformers](https://arxiv.org/html/2512.22323v1)，尤其4.2节。此处不是同名视觉编辑基准论文。
