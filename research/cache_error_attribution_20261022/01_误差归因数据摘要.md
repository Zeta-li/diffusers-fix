# 缓存误差归因与输出校正诊断

生成时间：2026-10-22T22:08:24.230433+08:00。状态：**complete**。

本轮固定三个公开演示输入、R2 计算区域、8 步与首尾全图刷新。比较 D/V/K/B 四条各自演化的轨迹；V/K/B 每步额外执行同当前状态的 dense oracle。这里的运行时间和前向次数是研究成本，不是部署加速结果。

D 为完整原生轨迹；V 用 oracle 替换 active 输出、保留 inactive 复用输出，并把 dense active 写回 velocity cache；K 保留 local active、以 oracle 替换 inactive；B 保留原局部输出。oracle 不写入 local cache。

记录误差的张量口径：`active_error/inactive_error/combined_error: raw local before mixing vs same-current-state dense; returned_error: mixed returned target output vs same-state dense`。

active/inactive/combined 字段均是混合干预前的 raw local 对 dense；returned 字段记录最终混合输出。V 的 returned SSE 应等于 raw inactive SSE，K 应等于 raw active SSE，B 应等于 raw combined SSE；这只是同状态坐标替换恒等式。误差 count 为标量元素数，即 token 数乘通道数。
