## 3 最终可复现协议

### 3.1 冻结清单

每次新运行创建新 run ID，不覆盖旧结果。冻结以下内容：

- 基座 revision、Lightning 文件SHA、学生与策略头SHA、代码commit及未提交diff；
- 来源ID、原图SHA、原prompt及来源侧修订、ROI、request key、分组角色；
- 显式噪声或CPU生成器种子和张量SHA；不能仅记录一个整数seed而忽略生成设备；
- 8步时间表、CFG、dtype、输出尺寸、VAE tiling、缓存/学生开关、计时边界；
- 质量门、语义评分规则、候选选择准则、配对重复数及最大DiT预算。

### 3.2 训练

从已冻结pilot checkpoint启动扩量训练，Train128×4 distinct seed，共512微批，梯度累积4；选择窗口前推进学生自身状态，再取同状态稠密教师。固定学习率5e-5，AdamW weight_decay0.01，clip1，rank8。训练scale仅用Train，Cal/Dev/Test不得参与梯度或尺度估计。保存每个窗口的来源、seed、起始步、损失分项、实际DiT及checkpointSHA。

由于最终R25比原训练局部时程增加完整刷新，后续如专门在R25时程重新训练，应命名新模型并记录训练分布变化；不能覆盖LOCAL128后仍声称同一权重。

### 3.3 质量验证

1. 同源、同噪声执行F与候选，先做公共前缀和全选合同。
2. 保存每步state、velocity、所选indices、缓存年龄与输出PNG；教师额外调用单列。
3. 固定区域计算RGB/内部/域外/latent误差；分母与掩码一致，空区域单独标记。
4. 匿名组织全来源图像，先冻结评分后揭盲；保留失败与不确定，报告审阅者性质。
5. 同时报告相对F误差与相对源图/指令的语义正确性，不能用一个代替另一个。

### 3.4 净延迟

模型驻留，同步CUDA；三臂各一次预热，固定8来源，每臂每来源3次轮转重复。计时含计划、条件编码、8次DiT、解码、PIL、缓存清理；排除模型加载、磁盘IO与审计哈希。计时后与质量实验核对RGB哈希，再做来源平均及来源bootstrap。报告峰值显存，并检查forward恢复与缓存释放。若质量不达标，明确称诊断性性能，不能写成可部署质量下的加速。

### 3.5 文件先保存再释放机器

运行后先生成文件清单与SHA，下载至本机，对每文件验证；再打开随机图和回读关键checkpoint。远端包已创建但未下载，或本地只有汇总，均不等于已归档。至少另存一个独立磁盘/可信云副本后再释放远端存储。当前机器已停止，因此本交付只保证本地已有内容，缺失项见审计。
