# C2 单轮闭环补采后的目视检查

2026-10-23，检查者为研究助手，配置名可见，非盲评。本记录在读取 C2 数值质量汇总之前写下；已查看全部八张完整对照面板。源图和输出哈希见 `data/panel_receipts_c2.json`。F 为完整八步参考，不是人工编辑真值；LPIPS 接近 F 不能替代语义检查。

| 源 ID | B0/B1 目视结果 | 尚存问题 |
|---|---|---|
| 101594 | 都生成玩沙动作，B1 手臂/手掌位置略异于 B0 | 成人上身、风筝处的水平淡化带与背景竖向拼接仍然明显；未见 B1 修复该失败 |
| 65261 | B0/B1 与 F/R2 非常相近 | 酱汁主要形成食物之间的池状填充，而不是明确淋在顶面；属于 F 也有的语义疑点 |
| 139294 | B0/B1 都准确生成 Welcome；文字下方的背景比 R2 的水平亮度带更平滑 | B0/B1 未见明确优劣，不能把相似的结果判成 B1 独有收益 |
| 398172 | B0/B1 近似，水流与 R2 不同，象鼻下垂 | 水源仍不在可见鼻尖；有多段象牙和不自然的水流连接。F 自身也有水源不合理，但局部候选未恢复物理关系 |
| 175520 | B0/B1 都添加多张贴纸，布局较接近 F；内容略有差异 | 开放式贴纸内容差异不应直接记为语义失败；没有明显 B1 边界优势 |
