# C1 因果诊断与结构完整扩边：实验协议与进度

日期：2026-10-23（Asia/Shanghai）。执行环境：zeta 单卡 H800（用户确认）；代码基点 `4222cd5955b8033842748a7d676a5d180ab4c22d`。本阶段独立保存，不覆盖 Val16 或 Train8 的冻结记录。

## 研究问题

Val16 已证明固定局部执行有约 11%–12% 净节时，但现有 Train8 逐通道 Value 校准没有可靠优于无样本先验，且存在语义和结构失败。本阶段首先检验误差机制，然后比较结构选区，最后依据证据决定是否补采拟合。

## C1：同状态干预

使用原 Train8、原图和 latent、原八步时间表。每个中间步从同一无校正学生状态分出 NONE、B0、V_ORACLE、KV_ORACLE。只有 NONE 推进 scheduler；密集 donor 每步仅查询一次。V 是 attention 前 raw Value；K 是 QK 归一化和全局 RoPE 后的 Key。干预仅替换非活跃目标在临时拼接 attention 输入中的读取，原始缓存不回写。

主指标为每源图六个中间步的活动目标 velocity SSE 之和。每图计算相对 NONE 的下降比例，再对八图等权平均。辅助指标为 BF16 一步 Euler 误差、完整目标与非活跃目标误差。六个步不作为独立源图。

在任何真实模型 C1 查询前固定工程筛查门槛：V_ORACLE 的源图等权平均活动 SSE 下降至少 10%，且至少 6/8 源图下降，所有有限值与正确性检查通过，才允许 C2 一次补采。该门槛用于控制研究投入，不是显著性检验，也不是终图质量验收。若 V 无效而 KV 有效，再讨论 Key 方向；不能把 KV 与 V 的条件效应解释成可加贡献。

正确性要求：基线每步输入、预测和 Euler 后 latent 与旧 Train8 哈希一致；八张 NONE PNG 完全重现。每次 probe 前克隆完整缓存，分支与主轨迹存储隔离；donor 和每个分支后逐张量检查全部主缓存、velocity、年龄与 trace；分支的非活跃原始 K/V 不变。CPU 检查独立验证归一化后全局 RoPE 的 K 与 raw Value 的捕获位置，并验证非连续文本 mask、FP32/BF16 和 scheduler。

## C3：先冻结结构选区，再生成

训练内部探针固定为 Train16 第 9–16 个源图，未参与 Train8 拟合：101594、65261、139294、398172、175520、5142、185890、495435。仅读取源图、标注和指令，不读取目标图。检查与 Train8、旧 demo、Val16 和探针内部的源内容重复；保留全部预选 ID，不按生成好坏替换。

在首次生成这些探针图之前，依据源图和指令标出完整接触结构，形成 CLOSE，并构造严格相同实际 token 数的普通距离扩张 PLAIN。二者都包含原 R2，额外预算上限为 R2 外背景 token 的 1/4；超预算记不可行，不截断结构。人工源图先验只作为机制验证，不冒称自动选区算法。

比较 F/R2/PLAIN/CLOSE，固定八步、种子、校正 none 和原公共评价区。即使计算区域扩大，远背景评价区也保持原 `~R2`。最多 256 次 DiT；若预算不可行，保留原因并分别记账。核心判断是 CLOSE 是否优于等 token 的 PLAIN，不把多算的收益归因于结构。

## C2：仅证据支持时执行

若 C1 满足上述 Value 空间门槛，使用冻结 B0 在原 Train8 上补采一次同状态 dense 标签，固定原采样位置。原/新矩按每源图 1/2 混合，固定 eta=0.01 拟合 B1。仅八个独立源图，无主模型梯度更新。在上述训练内部探针比较 F/R2/B0/B1，不用探针拟合。名义补采 112 次 DiT、探针 256 次，计 368 次；不循环补采直到 Val 变好。

## C1 已完成的关键发现

按预登记的源图等权活动 velocity SSE，B0 平均下降 78.4372%，V_ORACLE 下降 83.3925%，KV_ORACLE 下降 100%，三者均在 8/8 源图改善。该同状态诊断支持存在 Value 校正空间，但 B0 本身已有显著同状态收益仍未在 Val16 达成可靠终图质量，因而不能把上述百分比写成编辑质量提升。

非活跃 velocity 未被这些读取校正更新；其误差占 NONE 完整目标 SSE 的源图平均比例为 32.6953%。因此 KV_ORACLE 的活动误差归零不等于全部目标误差归零。新的补采仅检验闭环状态分布错位是否可通过单轮重采缓解。
