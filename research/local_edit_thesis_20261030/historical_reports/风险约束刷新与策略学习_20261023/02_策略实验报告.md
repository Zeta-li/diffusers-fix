## 1 研究问题与方法

本阶段把学习目标从直接外推整个域外速度，改为选择需要真实重算的目标 token 组。每次选中的目标都通过原局部执行器的完整 Transformer 层链，并更新真实 K/V、velocity 和年龄。策略不直接生成 velocity，也不使用部署时 dense donor。

核心 R2 全程保留。域外按预冻结 SHA 顺序划分为四个等 token 数组，最多三个余数 token 每个中间步都真实更新。分组边界可切开少量 2×2 tile，因此它不是完整接触结构选区。令目标数为 N，核心数为 C，余数为 r，每组 q 个 token，则六个中间步合计使用六个组单位：

$$\sum_{k=1}^{6}\operatorname{popcount}(a_k)=6,\qquad T=2N+6(C+r)+6q.$$

ROTATION/STATIC/IL/PPO 在同一源上的完整八步目标 token 总数严格相同，时间分配可以不同。B0/B250 作为额外参照单列，不宣称与这些新策略等 token 或等秒。

全部新组策略使用冻结 B0 Value 校正。中途真实刷新产生的新锚点配对在旧表中未观测时回退 identity；这部分代价在下文单列。策略变化同时改变新鲜 K/V、velocity 与哪些 Value 校正仍适用，不能把观察到的收益全部归为时间预算分配。

## 2 训练、奖励与公平性

Train8 每源执行 F 参照和四条探索轨迹（ROTATION/FRONT/BACK/RANDOM）。STATIC 只按八源训练平均奖励选一次；监督初始化使用每源四条中最佳的一条，共 8×6=48 个相关决策状态。每个 PPO 轮次包含全部八源各一次，共八轮、64 个真实图像编辑 episode。状态不是独立图像样本，训练奖励不是泛化结果。

策略输入为54维当前可观测状态，使用两层64宽度网络、16个可行组子集动作和价值头。硬动作 mask 保证所有轨迹恰好消费六个组单位，终端奖励为：

$$R=-\frac{\operatorname{LPIPS}(I,I_F)+\operatorname{MAE}_{band2}(I,I_F)+2\max(\operatorname{extraBG}(I),0)}{0.05}.$$

该奖励是模型 F 一致性与背景保持代理，不是指令成功奖励，也没有经验证的风险概率上界。F 可以包含错误；负 extraBG 只表示比 F 更接近源背景。除终步外奖励为零。PPO 使用固定最终检查点，IL 与 PPO 在 Probe 开始前一起冻结。

## 10 下一步与论文结论边界

具体有界协议设计见 [下一阶段算法与可证伪实验](06_下一阶段算法与可证伪实验.md)：首级最多408 DiT，完整条件预算1976 DiT，均未执行、单独计账。

下一阶段优先级是：以 FRONT 为必比固定基线，先处理真实刷新后 anchor=1/2 的校正覆盖与背景伪影；在同一时间预算和严格相同 token 数下验证完整接触结构分组；随后才用已隔离的新来源检验样本效率与泛化。不能继续对当前 8 源增加 PPO epochs 后用已见 Probe 选择最好模型。若策略最终仍复现固定时程，应选择成本更低的固定方案，并把 RL 作为受控负结果。
