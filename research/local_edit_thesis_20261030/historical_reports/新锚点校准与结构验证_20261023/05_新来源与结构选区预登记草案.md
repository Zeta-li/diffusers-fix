## 2. 独立脚本与可复现采集

新入口为 [prepare_new_sources.py](scripts/prepare_new_sources.py)，不修改旧解码器、选样清单或协议。默认 `--mode plan` 仅校验和冻结元数据；它不导入模型、不联网、不读取新源图。该模式检查未来名单/父清单/库存的校验和、固定 revision、首轮定位、官方 split、组隔离、排序哈希及全部40个 locator，并记录实际提取前尚未知的 source/mask SHA，绝不编造原图哈希。

后续显式 `--mode prepare --asset-mode http-range --attempt <新名称>` 才读取媒体。它复用原 `prepare_magicbrush.py` 中的审计 Range reader，并在动态导入**之前**核对冻结 decoder amendment 的原脚本 SHA。执行产物同时记录导入代码 SHA。每个请求要求精确206、Content-Range、总长与长度相符，并检查同对象 ETag。先解析 footer，再设置 `target_img` 列块禁读范围；所有实际 Range 和 forbidden target ranges 分别写入该 attempt 的 `network_ranges.jsonl`、`parquet_layouts.jsonl`。

只投影 `img_id, turn_index, instruction, source_img, mask_img`。只允许冻结 train/dev 行组，不打开任何 Test shard；目标字段的 schema/footer 元数据可解析，目标图像 payload 禁止请求、解码或保存。源图和掩码的读取粒度是行组，可能传输同一行组的其他源图 bytes；仅解码、导出冻结40行，不能写成网络恰好只传输了40张图。

离线 `--asset-mode index --asset-index <文件>` 可核验已落盘 bytes、SHA和定位，要求索引声明列投影、固定版本和未读取 target/Test。路径先解析真实位置，禁止指向 outputs/Test 的软链接及大小写变体。但自报索引不能独立证明 bytes 来自官方冻结行，所以该模式保留 `PROVENANCE_REVIEW_REQUIRED`，不将其自动升级为来源完整性通过；实际执行优先用有 Range 收据的路径。

默认输出根为 `data_d3_sources/`，首次冻结 `source_preregistration.json`、`asset_requirements.json`。每次 prepare 必须给新的 attempt 名；源图/掩码和 JSON 均不可覆盖。新产物预期为：

| 产物 | 内容与验收要求 |
|---|---|
| `inputs/{new_train24,dev16_new}/{id}/source.original`、`mask.original` | 原始bytes、源和mask SHA、大小、固定 locator、版本URL与采集方式 |
| `attempts/<name>/qc_report.json` | 40行完整冻结顺序；缺失、失败、重复、灰区、全图回退逐例保留 |
| `attempts/<name>/cases_new_train24.json`、`cases_dev16_new.json` | 几何、源图签名、R0/R2、binary-mask SHA；默认 `ready_for_model_outputs=false` |
| `attempts/<name>/source_only_review_form.json` | 源图可见性、掩码对齐、指令指代、接触/支撑歧义等空白复核项 |
| `attempts/<name>/network_ranges.jsonl`、`parquet_layouts.jsonl` | 实际网络及 target 列块禁读审计；离线模式无此网络支出 |

本地命令示例仅说明入口，本文未运行媒体提取：

## 3. 来源 QC 与许可记录

QC 不读取 F 或其他生成图，也不以编辑类型、ROI大小、颜色或困难程度筛选样本。先检查 bytes 可解码、EXIF、源与mask比例，记录 RGB内容 SHA、64位 average hash 和 difference hash。对35个旧签名及全部新源两两进行既定检查：原始 SHA 或带尺寸RGB SHA相同为精确重复；两种感知距离均≤6且宽高比对数距离≤0.02为拒绝；其余任一距离≤10为源图复核灰区。检测未命中只表示未命中此规则，不能证明任意裁剪、翻转或复杂语义内容都不重复，也不能声称已完成 Test 的感知去重。

缺失、损坏、无法确认极性或对齐、重复项均保留 ID 和原因并阻断；不静默换下一张，不把灰区自动当通过。灰区只能由源图对照裁决并保存独立记录；不得参考生成质量。脚本会保留40行，包括提取失败行，不能通过只汇总成功项改变分母。

许可记录沿用已有 [数据来源核验](../小样本校准启动_20261023/data_source_evidence.md)：该文记录官方 MagicBrush LICENSE 为 CC BY 4.0。脚本保存该本地证据的 SHA、官方许可链接、固定版本数据卡、论文与作者署名；本轮没有再次联网核验许可，也没有推断每张原始 COCO 图的独立权利条款。正式归档仍应保存官方许可快照及来源署名；不能以数据集许可替代基座模型许可。

## 4. 合法全图回退与真正错误分开

继承 alpha_v2：非不透明 RGBA mask 以 `alpha==0` 识别明确编辑区，以 `alpha<255` 纳入抗锯齿边缘；完全不透明灰度mask用白色正区域。没有明确透明编辑区的不明半透明mask、不透明彩色mask、空mask、未经验证的EXIF/比例变换均阻断。

合法全正mask、R2 bbox加halo覆盖全图，或背景不足4个token时，按此前06后续设计保留来源，标记完整计算回退及原因，所有8步完整目标计算，不生成不存在的 inactive 标签。这是新执行级的明确回退合同，**覆盖旧Train8解码器对合法全图ROI一律拒绝的行为，但不改旧文件或旧结果**。真正无法解码/对齐的输入不能冒充合法回退。

自动 R0 是标注bbox在输出16px网格向外取整，R2是在其四周扩2token。目标面积1048576，宽高按原Qwen公式取最近32的倍数，mask最近邻映射。记录原/目标尺寸、bbox、indices、mask哈希、回退和有效背景数。该结果只是已有人工mask的固定几何基线；D2冰箱与鸟案例已说明原mask可能没覆盖实际变化或非目标误改，因此仍需要源图与指令复核，不能把几何通过当语义范围正确。

## 5. 独立冻结结构选区

自动QC后、任何新来源 F/FRONT/校正结果生成前，仅依据源图、指令及已有mask另建 `structure_regions` 清单。该清单不是本脚本自动输出，也不是已经完成的自动创新。每源记录原R2、目标对象、直接接触/支撑对象、是否纳入及理由、源图SHA、标注者/时间、手绘多边形与离散token索引。模糊边缘保留不确定性，不能先看生成失败再移动边界并仍称前置冻结。

两臂都含原R2。`CLOSE_K` 用原R2并入完整可见支撑对象，令其token数为K；`GEO_K` 从原R2按固定距离、坐标排序普通扩展，**严格到相同K**。分别由各自核心重建四等组和余数，冻结seed、组索引、六步FRONT时程；K、余数r、组大小q相同，逐步选中数与总目标token账本均相同。条件图/text始终更新，两臂校准关闭以排除表覆盖差异。

预定可行上限为K/N≤0.5；无法明确闭合、超限或无法等额的情况，两臂都完整回退并计费，不能裁去支持对象来伪造闭合可行。相同选区等退化配对保留但标为没有几何对比信息。全部16个Dev源及有效m源分别报告；有效配对不足8/16时只作可行性记录。严格同token仍不保证真实延迟相同，执行时须单列规划、gather及attention开销。
