## 摘要

局部扩散执行会同时引入缓存上下文误差与未重算区域的速度误差。已有实验说明，减小训练来源上的局部误差并不足以保证闭环终图质量；在当前动作空间与八个已见开发来源上，PPO 也未表现出超出固定提前刷新规则的增量。下一阶段因此固定刷新时程与原选区，只研究真实刷新后新锚点上的有界仿射校准，分别作用于注意力原始 Value 和当前未重算区域的 velocity。研究顺序为训练内留一代理检验、同状态机制对照、闭环终图检验，再视证据决定是否扩大训练来源、验证结构完整选区和重新进入策略学习。当前方法是待证伪假设，不主张完全消除误差、无损加速或 RL 必要性已经成立。

## 1. 已有结论与本轮干预范围

上一阶段累计完成 176 请求、1456 次真实 DiT。PPO 真实执行了 64 个训练 episode、64 次优化更新，训练期间有 32 种随机动作序列；但在 Probe8 的确定性推理中，STATIC、IL、PPO 的六步动作均为 `FRONT=[15,3,0,0,0,0]`，八源输出 PNG 逐源相同。三者平均 LPIPS/F 为 0.032073，低于 ROTATION 的 0.069440，严格数值通过数却由 ROTATION 的 5/8 降至 4/8。共享额外轨迹的 IL_PLUS 对照也没有使相应继续门成立。因此当前 PPO 扩大实验暂停，192 次条件计时预留不执行。

这一结果支持把 FRONT 保留为强规则基线，不支持把 FRONT 的收益归因于 RL，也不证明任意输入、其他动作空间或更大来源规模下 RL 都无用。旧 29,696 参数 velocity 残差头在 Probe8 上相对 B0 为 1 好 7 坏；C5 又表明它在训练来源自身闭环状态上仍可降低部分同状态速度误差。失败不能简单归因于“没有训练”或“完全不会预测”，也不能从相关性认定单一失败机制。

当前 FRONT 的 stale 读取对应真实刷新后的 anchor=1/2，而旧校准表主要覆盖 anchor=0，实际依赖 identity 回退。本轮固定 FRONT、原 R2、原四等组、模型、LoRA、8 步、CFG=1 和 BF16，只改变临时校准读取。固定项不能在看到拟合或终图结果后同时调整。

证据入口：[上一阶段策略报告](../风险约束刷新与策略学习_20261023/02_策略实验报告.md)、[动作等价审计](../风险约束刷新与策略学习_20261023/data/policy_equivalence_audit.json)、[C5 报告](../风险约束刷新与策略学习_20261023/03_C5闭环误差诊断.md)。

## 2. 统一状态表示与两类误差

记第 t 步目标 latent 为 z_t，本步真实计算集合为 S_t，未重算集合为 U_t。每个 token i 的真实锚点是最近一次经过网络计算的步号 s_i，不是缓存年龄；年龄为 t−s_i。完整教师在**同一当前 z_t** 上产生速度 v_t^*，它与学生共同使用提示词、条件图和真实 timestep。

对于第 l 层，raw Value 校准对象为 V_{l,s_i,i}，其目标是 dense 教师当前状态产生的 V^*_{l,t,i}。Value 不经过 RoPE；原始 Key 的归一化和 RoPE 语义保持不变。域外速度校准对象为真实缓存速度 v_{s_i,i}，目标为 v^*_{t,i}。两者分别影响：

| 路线 | 当前步的主要作用位置 | 不能由该路线单独保证的事项 |
|---|---|---|
| V 校准 | 改变活动 token 读取的缓存上下文，从而可能改变其当前预测 | 不能补回当前 Key、隐藏状态、未重算 token 的网络计算；Value SSE 下降不等于活动输出改善 |
| U 校准 | 替换当前 inactive token 返回给 scheduler 的速度 | 不能把预测值当作真实刷新；当前同状态活动输出须保持不变，但后续 latent 改变后活动输出可以自然改变 |
| V+U | 同时干预上述两处 | 两项效果并非独立可加，也不能把降幅之和解释为误差原因占比 |

只在真实计算集合 S_t 上更新 K/V、原始 velocity 和真实锚点。校准结果是临时估计，不写回这些原始缓存，也不能将其年龄重置为零。

## 3. 新锚点有界仿射模型

### 3.1 为什么先选择这个模型族

对固定 layer、目标步 t、真实锚点 s 和输出通道 c，设历史观测为 x，dense 同状态目标为 y。本轮模型为：

\[
\widehat y=a x+b=x+\big[(a-1)x+b\big].
\]

它可理解为 identity 附近的线性残差头，没有空间卷积和内容编码；与旧神经残差头共享“预测未计算结果”的目的，但参数化、输入信息、训练方法和部署算子不同。本轮可以检验在当前缓存观测条件下，最简单的可审计映射是否有稳定信号，不能预先认定更简单就必然泛化更好。

“最小”指模型族和执行算子简单，并不等于总参数数更少。九种配对下，V 的有效 a/b 共 `60×9×3072×2=3,317,760` 个系数，纯 FP32 约 12.66 MiB；现有完整 8×8 表实际分配约 90 MiB。U 只有 `9×64×2=1152` 个有效系数，约 4.5 KiB，完整表为 32 KiB。两路必须分别报告存储、临时 gather 和 affine 开销，不能把 V 表也描述成比 29,696 参数旧头更小的参数模型。

### 3.2 来源等权矩与约束

同一 pair 中，第 j 个来源有 n_j 个样本。先计算每源的原始一、二阶矩，再对有该 pair 的来源等权：

\[
\mu_x=\frac1m\sum_{j=1}^{m}\frac{\sum_i x_{ji}}{n_j},\qquad
E[x^2]=\frac1m\sum_{j=1}^{m}\frac{\sum_i x_{ji}^2}{n_j},\qquad
\operatorname{var}(x)=E[x^2]-\mu_x^2.
\]

协方差、μ_y 和 E[y²] 同理。此顺序保留来源间均值差造成的方差；不能先对各源单独中心化后平均方差，也不能把 token 多的来源赋予更大拟合权重。

\[
\lambda=\eta\,\operatorname{mean}_{c}\operatorname{var}(x)+10^{-12},\quad
a_{raw}=\frac{\operatorname{cov}(x,y)+\lambda}{\operatorname{var}(x)+\lambda},\quad
b_{raw}=\mu_y-a_{raw}\mu_x.
\]

η 固定取 `{10⁻⁴,10⁻²,1}`。随后**独立裁剪已经求得的 a_raw 和 b_raw**：

\[
a=\operatorname{clip}(a_{raw},0.5,1.5),\qquad
b=\operatorname{clip}\left(b_{raw},-B_c,B_c\right),\qquad
B_c=0.25\sqrt{E[y_c^2]}+10^{-6}.
\]

裁剪 a 后不重新拟合 b。该操作不再是无约束 ridge 的精确最优解，可能增大 SSE，因此必须记录截断计数和前后误差。边界是保守约束，不是终图质量保证。同时间和未观测 pair 均为 a=1、b=0。

### 3.3 留一来源检验与选择偏差

每次留出一整张来源，其余七源重新汇总矩，训练折内独立计算方差、λ 和 RMS(y) 边界。对留出来源 j，评价规则固定为：

\[
R_j=\frac{\sum_{l,t,s,i,c}(y_{jltsic}-\widehat y_{jltsic})^2}
{\sum_{l,t,s,i,c}y_{jltsic}^{2}+10^{-12}},\qquad
\overline R=\frac18\sum_{j=1}^{8}R_j.
\]

源内部保留实际采样和能量权重，不是 layer、pair 或通道等权归一；源之间等权。选择 FP64 有界留一均值最低的 η，精确平局取较小者。代理继续门为：

\[
1-\frac{\overline R_{corr}}{\overline R_{identity}}\ge0.10,
\qquad \#\{j:R_{j,corr}<R_{j,identity}\}\ge6.
\]

identity 平均误差为零时，不人为制造改善或批准晋级。V/U 独立选择 η、独立判门。由于选择和判门共用这些训练内折，结果只是进一步做机制筛查的依据，不是未见来源泛化证明。

拟合与上述评分使用 FP64。部署表保存 FP32，另报告 FP32 系数提升回 FP64 后的 affine 误差；这项诊断不参与 η 选择，也不包含真实 BF16 算子舍入。若 FP32 最近舍入使 b 越过 FP64 界，保存时向零调整一个 `nextafter`，此规则已写入拟合元数据。

## 4. 只读代码复核及部署合同

### 4.1 已核实的统计衔接

[run_fit_v2.py](scripts/run_fit_v2.py) 先要求 D0 v2 完成、8 个来源齐全、旧 FRONT PNG 一致及冻结源码摘要一致；逐源核验矩文件 SHA、来源 ID、样本计划 SHA 和 seed。V 精确检查 60×9 个 pair，U 检查 1×9 个 pair，并将每条 n 与冻结样本计划中的对应原坐标数量核对。V/U 总样本数、通道宽度及全八源覆盖也分别检查。

拟合调用冻结的 [bounded_fit.py](scripts/bounded_fit.py)，保存完整 NPZ 和小型报告。返回 `route_b.alpha/beta` 为 FP32，几何为 `[layer,t,s,channel]`；`summarize_fit` 不把密集系数展开到 JSON。上述静态逻辑与既定来源等权、折内裁剪、SSE 评分口径一致，未发现统计接口阻断。但这不是对尚未完成的实际采集数据发放通过证明。

### 4.2 V 的既有可用接口

旧 `deployment_route_b` 将 beta 映射为 delta，并按 `[layer,t,s,head,head_dim]` 重排。该顺序与 collector 将历史缓存的 head/channel 展平、dense `to_v` 输出保留原通道顺序一致。`ValueFittedExecutor` 的实际读取使用：

\[
\widehat V_{l,t,i}=\operatorname{BF16}\!\left(
\operatorname{FP32}(V^{raw}_{l,s_i,i})\odot a_{l,t,s_i}+b_{l,t,s_i}\right).
\]

读取前将本步真实计算 token 的临时有效锚点设为 t，保证 fresh token 走同时间 identity；inactive token 使用原始 s_i。它不是以年龄 t−s_i 直接索引 s 轴。校正返回新的临时值，不改 raw K/V。当前旧接口对此设计可复用，D1 仍需实际验证 identity 等价、非零表、混合 anchor=1/2、真实刷新和请求间清空。

部署还须把权重、LoRA、dtype、真实八步 timestep、拟合 NPZ SHA、训练协议 SHA 和调用源绑定。不能仅由调用者重新构造一个“看起来相同”的 contract，就认为任意系数已经匹配模型。旧 loader 元数据中的 `alpha_clipped=False` 只能表示 loader 没有额外裁剪，不能拿来否认本轮拟合阶段发生的裁剪；拟合报告中的实际 clip 计数必须保留。

### 4.3 U 必须新增的安全输出路径

旧 `LocalTargetExecutor.forward` 直接返回 `self.velocity`，返回值与真实速度缓存共享存储。U 路径必须先复制完整返回张量，再仅替换本步真正 inactive 的目标 token：

\[
\widehat v_{t,i}=\begin{cases}
v^{local}_{t,i},&i\in S_t,\\
\operatorname{BF16}\big(\operatorname{FP32}(v^{raw}_{s_i,i})\odot a^U_{t,s_i}+b^U_{t,s_i}\big),&i\in U_t.
\end{cases}
\]

不得原地改写原返回值，不得更新 `base.velocity`、`base.age` 或锚点记录，也不得修改条件图输出。旧 `VelocityRuntime` 的 `active` 是固定核心掩码，不能原样用于 FRONT 的动态刷新；本步 U_t 必须来自实际 selected indices 的补集。U 只用 synthetic layer=0 的独立表，不能把它传给 60 层 Value loader。

当前新阶段没有因此自动获得 U 部署已正确的结论。新增 tiny 检查至少应包含动态混合锚点、raw 缓存不变、活动输出逐位不变、identity 表逐位复现、非零 affine、未知 pair 回退、条件图不变及连续请求清空。真实 BF16 affine 与 scheduler 语义再由 D1/D2 校验。

### 4.4 D1 影子分支的动态状态问题

旧静态选区的 causal helper 不能未经适配直接替换成 FRONT。影子分支的起点应在**本步 FRONT 选区已安装、学生网络计算尚未发生**时冻结，或明确给影子分支恢复该步同一 indices。否则从旧快照复制出的 branch 可能沿用上一时刻的动态选区，使干预比较同时改变计算集合。

所有 branch 读取相同当前 z_t、原始缓存与真实锚点，独立拥有可写存储；dense 和 shadow 不更新主轨迹 scheduler。临时 Value 注入只替换正确原坐标的 inactive Value，不改 Key；U 混合只处理相同 U_t。活动、域外和全目标分别评分。无 inactive 的第 1 中间步保留为全目标控制，不伪造标签或对空集合求均值。

实际 Euler 必须使用已核验的零维 FP32 delta Tensor：`(z.float() + delta_tensor * prediction).to(BF16)`。不能用 Python float 替换后假设逐位等价，也不能把单独用 FP64 算出的理论一步误差当作真实舍入后误差。

## 5. 为什么严格先 D0、再 D1、最后 D2

| 环节 | 要排除的解释 | 已冻结的继续条件 | 证据边界 |
|---|---|---|---|
| D0：Train8 新锚点采集与有界拟合 | 当前新 pair 是否根本没有可预测的低成本关系；训练统计是否错用源权重或 heldout | V/U 分别满足上述留一代理门；九 pair 和 stale 覆盖可核验 | 训练内代理，不能宣布终图改善 |

D0 的成功采集计划为 8 请求、112 DiT；D1 最多 4 请求、104 DiT；D2 最多三个候选、24 请求、192 DiT，成功调用合计上限 408 DiT。工程失败、重试和影子分支必须另外据实进入账本，不能把条件上限直接写成已经完成量。两路 D0 都失败就不进入 D1；只有通过自身机制门的路线才进入 D2，两路都过才考虑 V+U。

D1 的 Value 校准器由全部 Train8 拟合，前四源并非独立 holdout；它只隔离在同一状态上干预的位置。D2 若有多个候选通过，按冻结的训练终奖和既定平局规则选唯一类别，然后才进入新来源，不能在 Dev16 上反复换 V/U/V+U。

## 6. 后续神经残差训练：仅在证据表明需要时进入

### 6.1 可加入的信息与闭环补采

如果 oracle 确有收益、有界仿射表达不足，而新来源证据又支持该机制，可单独预登记一个轻量残差头：

\[
\widehat v_{t,U}=\widehat v^{affine}_{t,U}+h_\theta(\phi_t),
\quad \phi_t=\{z_t,z_{s_i},v^{raw}_{s_i},t,s_i,\sigma_t,\text{condition},\text{mask},\text{boundary distance},\text{已计算区域摘要}\}.
\]

输入只能包含部署时已经可见的信息；若使用当前活动区域速度，决策时点必须是本步真实计算之后，不能把它偷用于计算前的动作选择。未计算区域的 dense hidden、teacher velocity 和最终 F 图不能作为部署输入。

闭环补采沿冻结候选自身轨迹，用同状态完整教师产生标签；教师不推进 scheduler。训练来源、补采次数、旧/新轨迹权重和唯一最终 checkpoint 在执行前冻结，最多做已登记的一轮修订，不能因为开发效果不好反复补采直到过门。所有轨迹继承来源组分区；高频补采来源不能自动占更高训练权重。

### 6.2 速度、一步与边界的联合损失

令 e_t=\widehat v_t−v_t^*。可考虑的未来损失为：

\[
L(\theta)=L_v+\lambda_zL_z+\lambda_{\partial}L_{\partial}+\lambda_rL_{reg}.
\]

\[
L_v=\mathbb E_{\mathrm{source},t}\frac{\operatorname{mean}_{U_t,c} e_{t}^{2}}{S_v+\epsilon},\qquad
L_z=\mathbb E_{\mathrm{source},t}\frac{(\Delta\sigma_t)^2\operatorname{mean}_{U_t,c}e_t^2}{S_z+\epsilon}.
\]

S_v、S_z 为仅由训练来源确定并冻结的尺度。S_z 不能再包含逐步 `(Δσ_t)²` 并将其约掉，否则所谓一步损失失去步长权重。在理想 FP32 同状态、同 delta 的 Euler 下，一步 L2 误差就是速度 MSE 的 delta² 缩放，并不提供独立的长期监督。**训练对 FP32 连续一步代理反传，真实 BF16 scheduler 只用于实际更新和验收**；不能对逐位相等、round 或非连续量化声称可微，也不能把代理优化写成已经直接最小化真实舍入误差。

对真实 token 网格中跨 S_t/U_t 的相邻边集合 E_∂，边界项可定义为：

\[
L_{\partial}=\mathbb E_{\mathrm{source},t}
\frac{\operatorname{mean}_{(i,j)\in E_{\partial},c}
| (\widehat v_{t,i}-\widehat v_{t,j})-(v^*_{t,i}-v^*_{t,j}) |}{S_{\partial}+\epsilon}.
\]

网格邻接不能由展平索引简单相加而跨行。若只训练 U，活动误差 e_A 固定，则该项约束的是 |e_A−e_U|，可能推动 e_U 迎合错误 e_A，与 e_U→0 冲突。边界项提供空间耦合，速度和一步项共享同状态误差信息，因此不能把三项损失包装成三个独立信息源。至少预登记“单一 velocity”“velocity + 时间权重”“velocity + boundary”及必要的组合消融，不因“看起来连续”就增加权重。未来 λ、尺度、残差幅度约束和消融数量需另行预登记；本节不是修改当前已经冻结的闭式拟合评分。

训练后的必要验收仍是自身轨迹终图、语义和未见开发来源；不能再次用训练损失下降替代这些门。即使误差有稳定下降，也不宣称完全消除：相同旧缓存观测可能对应不同当前上下文，有限特征存在不可辨识性，近似网络、有限样本和量化也均会留下残差。

## 7. 结构完整选区与同预算对照

结构扩边的主张是“编辑对象与直接接触、支撑关系可能需要联合重算”，而不是把核心面积越做越大。只用源图和提示，在查看新生成输出前冻结完整支持结构的标注及理由。令原核心为 C，完整结构候选为 H，K=|C∪H|：

- `CLOSE_K` 使用 C∪H；
- `GEO_K` 从 C 按预冻结距离和坐标次序普通扩展至恰好 K 个 token。

两臂均关闭校准为 identity，保持 FRONT、K、余数 r 和四等组大小 q 相同。首尾完整、中间六个 group-unit 的目标 token 总量均为：

\[
N_{target}=2N+6(K+r)+6q,\qquad q=\lfloor(N-K)/4\rfloor.
\]

不只核对总数，还核对每步目标数、文本和条件图成本。该对照能够检验所选几何及其后续轨迹的效果，但不是与原 R2 同预算；相对原核心增加的计算必须另列。人工构造结构只验证结构先验，不证明自动语义识别方法已经实现。

无法闭合、超出冻结 `K/N≤0.5` 上限或无法严格匹配时，两臂共同走已登记 full fallback并保留原因，不能删除困难来源或截掉支持对象假装闭合。全部来源与有效几何子集分别报告；两臂共同 fallback 不计为结构改善。完整整图与域外色块/接缝检查是硬要求，核心均值不能掩盖远处伪影。

## 8. 何时才重新进入监督策略与约束 RL

### 8.1 进入条件

重新启动策略学习至少需要：固定执行器和校准器在新来源闭环质量上有可信信号；选择和系数读取开销进入真实延迟；同预算 FRONT/ROTATION/训练选出的 STATIC 均已比较；动作确实能在不同来源带来不同且可观察的收益。若最优部署动作仍等于固定 FRONT，就没有理由仅为使用 RL 而增加策略网络。

本轮校准表只覆盖 FRONT 的九种 pair。换时程会改变真实锚点分布，不能假设它自动覆盖任意策略：必须限制动作到有覆盖的情形，或预先采集新的训练 pair，并记录未知 pair identity 回退。不得将缺表样本自动插值、伪标为已校准或以旧 FRONT 训练成绩证明新策略稳定。

### 8.2 预算与质量约束的角色

令动作 a_t 选择真实刷新组，成本为实际 group-unit/目标 token。未来可研究：

\[
\min_{\pi}\mathbb E[T_{e2e}],\quad
\text{s.t. }\sum_t c(a_t)\le B,\quad
\mathbb E[D_{perceptual}]\le\tau_p,\quad
\mathbb E[D_{boundary}]\le\tau_b,
\]

并单列指令达成和新增明显伪影率。固定预算约束可以由动作 mask 强制；质量阈值只能通过训练与独立评价检查，有限样本下不能保证逐图不失败。奖励中的加权惩罚、critic 的回报预测、事后通过率门分别属于不同机制，都不能自动称为“已经校准的风险概率”或严格质量保证。

全图刷新属于付费动作，不能作为预算外免费的安全回退；它也无法撤销先前轨迹累计误差。若以后使用风险预测器，需要单独的训练/校准/评价分工和风险可靠性检查。部署策略状态不得包含教师、完整当前隐藏状态、未来结果或本步尚未计算的速度；训练 reward 可以使用训练来源教师/F，但其额外前向、图像评价和墙钟成本必须全部计账，不能成为推理侧免费信息。

### 8.3 SL 与 RL 的公平比较

至少比较固定 FRONT、同预算规则、仅训练源选定的 STATIC、行为克隆 IL、共享额外轨迹的 IL_PLUS 和序列 RL。它们应使用相同来源、教师参考和可用轨迹预算，完整报告优化次数、墙钟及额外奖励计算；不能把 PPO 比 IL 多看 64 条在线轨迹产生的收益归因于 RL 更新方法。

先验证整轨迹选择或 contextual bandit 是否足够；只有逐步观察状态优于固定 schedule 与一次性选择时，才有序列控制的必要性证据。PPO 等方法的 checkpoint、超参数、训练 seed 和开发继续门先冻结，评价多个策略训练 seed，并把来源作为独立统计单位。共享数据控制并不自动使所有优化计算量相同，仍需单列成本。
