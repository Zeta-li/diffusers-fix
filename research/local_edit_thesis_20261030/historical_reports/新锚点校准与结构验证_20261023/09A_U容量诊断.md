# 09A：U 校准容量诊断——增加数据能否消除当前误差？

日期：2026-10-25。性质：使用已冻结 D0 v2 原始统计矩的事后探索，**0 DiT、0 GPU、0 网络、0 新媒体读取**。本诊断没有进行新的交叉验证、超参数搜索、闭环生成或终图评价；不改变 D3 的 U-only 类别、η=0.01、边界、门槛或任何部署参数。

**主要观察：即使为每个旧训练来源单独用其教师标签拟合，当前逐通道仿射模型相对共享表仍只能进一步消去约 4.97% 的平均残差。去掉正则与系数边界、取同源无约束仿射最小 SSE 后，仍保留共享表平均残差的 95.03%。**这提示“多训几轮同一个仿射模型”不是当前旧状态上消除误差的主要途径；扩大独立来源仍有必要，因为它检验的是共享关系的覆盖与泛化，不能由本诊断判为无效。

## 1. 数据与比较对象

使用原 Train8 的八份 `data_d0_v2/d0_U_*.npz`，共 126072 个 token-step、8068608 个通道标量配对，但独立来源仍只有八张。每源保存九个真实 (t,s) 配对的 n、Σx、Σy、Σx²、Σxy、Σy²，x 是真实缓存的域外 scalar velocity，y 是同一当前 FRONT 状态的 dense 目标。原矩足以精确计算标量仿射 SSE，不需要重建或杜撰 token 样本。

| 对象 | 拟合数据及限制 | 此处评分含义 |
|---|---|---|
| Identity | a=1、b=0 | 原始 stale 速度误差基准 |
| 现有共享 Train8 U 表 | 原已冻结 η=0.01 与有界规则；读取原保存 FP32 系数 | 系数提升到 FP64 后对原始矩评分，复现原 training_errors |
| 每源单独有界仿射 | 每源用自己的标签拟合并在同源评分；η仍为0.01，完全复用原拟合与裁剪函数 | 使用评估来源标签的乐观诊断，不能作为新源可部署模型或泛化结果 |
| 每源无约束 OLS | 每源、每 pair、每 channel 独立最小化同源 SSE；不使用 ridge 或 clip | 仅是该特定仿射函数族在这批已见状态上的经验最小值；不是新的候选 η |

单源有界模型保留 a∈[0.5,1.5]、|b|≤0.25 RMS(y)+10⁻⁶，以及“先求 raw a/b，再独立裁剪，不重算 b”的原规则。其 RMS(y) 也来自该单源教师标签；这是同族规则，而非把共享八源的数值边界照搬为单源边界。共享表与全部八个单源表本次均无系数裁剪，故该区别没有通过 clip 改变本次结果。

所有比较均使用 FP64 仿射算术计算原始矩 SSE，**不包含真实 BF16 乘积/舍入、scheduler 误差或自身闭环状态漂移**。现有共享表的 FP64 重拟合及 FP32 保存系数均另行复核，不重新选择 η。

## 2. 计算口径与经验下界

沿用原 bounded_fit 的评分：先在每源内对所有已采 pair、token、channel 求 SSE 总和，再除同集合教师平方和，最后来源等权平均：

\[
R_j=\frac{\sum_{t,s,i,c}(y_{jtsic}-a_{jtsc}x_{jtsic}-b_{jtsc})^2}
{\sum_{t,s,i,c}y_{jtsic}^2+10^{-12}},\qquad
\bar R=\frac18\sum_{j=1}^{8}R_j.
\]

源内没有逐通道、逐 pair 再归一化。每个 pair/channel 的 SSE 可由原矩展开：

\[
\mathrm{SSE}=\Sigma y^2+a^2\Sigma x^2+n b^2
 -2a\Sigma xy-2b\Sigma y+2ab\Sigma x.
\]

对单源无约束 OLS，令 Cxx=Σx²−(Σx)²/n、Cyy=Σy²−(Σy)²/n、Cxy=Σxy−ΣxΣy/n，则：

\[
a^*=Cxy/Cxx,\quad b^*=\bar y-a^*\bar x,\qquad
\mathrm{SSE}_{min}=Cyy-Cxy^2/Cxx.
\]

Cxx=0 时采用常数预测均值、最小 SSE=Cyy；实际本次 4608 个单源 pair/channel 均未出现零方差。脚本同时计算系数展开 SSE 与中心化解析 SSE并核对，最大绝对差约 2.94×10⁻¹¹，属于 FP64 数值误差。共享表在固定 η 下重算得到的 FP32 系数逐位一致，与原训练内评分也一致。

## 4. 能解释什么，不能解释什么

1. **共享关系有一定损失，但不是本次旧状态全部残差的来源。**单源系数能解释部分来源差异；实际部署是否能从当前可得内容预测这种差异，仍需新的模型和独立来源验证。单源表已使用该来源 dense 标签，不能免费部署到未见图像。
2. **当前约束没有成为明显瓶颈。**共享表裁剪 0/576，单源合计裁剪 0/4608；无约束最小值与单源有界结果几乎相同。继续放松边界或增加同一闭式拟合的训练轮数，缺少当前证据支持；不据此放松原门。
3. **95.03% 绝非“不可约误差”或模型能力的普遍上限。**它只对每源、pair、channel 使用单个历史标量 x 的仿射映射成立。更丰富的当前状态、跨通道关系、空间邻域或非线性映射可能解释残差；现有矩不含相应协方差及 token 级结构，无法计算这些模型的最小误差，也无法判断信息不足与非线性表达不足各占多少。
4. **一步残差与终图质量不能线性对应。**本诊断没有取得任何新的终图、语义或延迟数据；即使同状态 SSE 接近经验下界，闭环传播仍可能累积或改变误差。也不能由单源 OLS 更低推出校准生成图必然更好。

因此，扩大 NewTrain24、形成 Train32 的作用应首先是检验共享关系的覆盖和未见来源闭环收益，而不是承诺“多给样本就能清零”。若新数据只让训练代理下降、开发集终图仍不改善，应转向受控比较更丰富输入或空间校正，并明确代价；RL 也不能从现有仿射残差下界获得直接有效性证明。
