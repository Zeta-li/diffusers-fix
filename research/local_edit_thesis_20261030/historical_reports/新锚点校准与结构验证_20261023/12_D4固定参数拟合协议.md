# D4 U-only 固定参数拟合协议与独立验收建议

**状态：新实现的执行前协议草案；本拟合未执行。** D4 真实采集状态以其实际 ledger/status 和独立审计为准。本文件不预先声明 D4 成功，不授权 D5、Dev、RL，也不修改 D0 的历史参数选择记录。

## 1. 研究问题与来源范围

本轮只回答：保持已选 U 仿射函数族与 η 不变，将来源从旧八源扩展到 **31 个具有真实 inactive 标签的训练来源**后，充分统计量、参数覆盖及同状态预测误差如何变化。这里“训练”是固定模型下闭式参数估计，没有更新 Qwen 主干、没有神经网络梯度优化、没有 RL。

来源固定为旧 D0 八份 U moments，加 D4 的 23 个新局部来源。NewTrain24 中 `mb_newtrain_363308` 原始全图回退保留在采集 24 源及 330 调用分母中；它没有 inactive 标签，因此不伪造零值样本、不进入 U 拟合。不能因某个来源的语义、误差或画面表现不好而继续排除它。

| 数据/结果 | 来源数 | 可支持的结论 |
|---|---:|---|
| 旧冻结八源 U 表在新 23 源上的误差 | 23 | 新 23 源未参与旧系数拟合或旧 η 选择的同状态代理误差 |
| 新固定 η 表的训练内误差 | 31 | 拟合所见来源的同状态误差，属于训练内结果 |
| 新固定 η 留一来源诊断 | 31 个留出来源；每折训练 30 源 | 固定函数族下的来源留一诊断；不选 η，不设通过门 |

旧八源仅有 moments；新 23 源有原始监督档案。不能写成“31 源都有逐 token 原始监督”。Dev、Probe、Test 不进入拟合、系数选择或本轮评分；未来独立验证需另行决定。

## 2. 不改变的参数估计

几何为 `layers=1, steps=8, channels=64`；U 使用 synthetic layer 0。覆盖恰为九个真实动态锚点配对：

\[
(t,s)\in\{(2,1),(3,1),(3,2),(4,1),(4,2),(5,1),(5,2),(6,1),(6,2)\}.
\]

每个配对必须有 **31 个来源**，并分别记录其 token 数。它们不是 31 个独立扩散状态；同源的多步、多个 token 有相关性，不能扩大统计独立样本数。

对一个配对和通道，先在每源内部将 sums 除以其实际 token 数，再对来源等权平均，形成 \(E[x],E[y],E[x^2],E[xy],E[y^2]\)。\(x\) 是该来源 FRONT_ID 自身闭环中真实旧缓存的 inactive velocity，\(y\) 是教师在完全相同当前状态上的 dense velocity。令

\[
\operatorname{Var}(x)=E[x^2]-E[x]^2,\qquad
\operatorname{Cov}(x,y)=E[xy]-E[x]E[y],
\]

\[
\eta=0.01,\qquad
\lambda=\eta\cdot\operatorname{mean}_{c}\operatorname{Var}(x_c)+10^{-12},
\]

\[
a_c^{\rm raw}=\frac{\operatorname{Cov}(x_c,y_c)+\lambda}{\operatorname{Var}(x_c)+\lambda},
\qquad b_c^{\rm raw}=E[y_c]-a_c^{\rm raw}E[x_c].
\]

这是保持原 identity prior 的 ridge 形式。随后分别限幅：

\[
a_c=\operatorname{clip}(a_c^{\rm raw},0.5,1.5),\qquad
b_c=\operatorname{clip}\left(b_c^{\rm raw},-L_c,L_c\right),
\qquad L_c=0.25\sqrt{E[y_c^2]}+10^{-6}.
\]

**必须先算原始 a 与原始 b，再独立 clip；不能在 clip a 后重新计算 b。** 沿冻结实现输出 FP32 系数；若最近舍入后的 FP32 b 超过原 FP64 限幅，则仅向零 `nextafter` 一次。未知配对、未来配对、同时间配对保持 `alpha=1, beta=0, coverage=false`。

脚本仅调用冻结 `bounded_fit.py` 的 `_validated`、`_aggregate`、`_coefficients` 与 `_error`；不调用会扫描 `ETAS` 的 `fit_bounded`，也不调用旧 `_gate`。旧源码及 moments 格式用 SHA 固定。η=0.01 的历史来源是旧八源曾在多候选中选出该值；本轮固定继承它，不能把这段历史改写成从未调参。

## 3. 误差口径与三个必须分开的报告

每个来源将其所有真实配对、token、通道上的 SSE 相加，再除以同集合教师原始能量：

\[
R_j=\frac{\sum_{(t,s),i,c}(a_{tsc}x_{jtsic}+b_{tsc}-y_{jtsic})^2}
{\sum_{(t,s),i,c}y_{jtsic}^{2}+10^{-12}},\qquad
\overline R=\frac{1}{M}\sum_j R_j.
\]

来源间等权；来源内部按实际采样 token 和教师能量隐含加权，**不等于配对等权、通道等权或每通道单独归一**。相对下降报告为 \(1-\overline R_{\rm candidate}/\overline R_{\rm identity}\)，不能换成逐源下降比例的平均。identity 均值为零时相对下降记为 `null`。

每源均保存 identity、候选 SSE、teacher energy、normalized SSE、scalar count 和 fallback pair count，额外汇总严格改善/变差/相等来源数。`fallback_pair_count=9` 在 identity 空表评分中是实现上的 identity 回退计数，不是数据缺少九配对；候选表九配对均覆盖，正常应为零。

1. **旧冻结八源表 → 新 23 源**：读取旧 artifact 的原始 FP32 系数，绝不在新标签上重拟旧表。新 23 源未参与旧表的系数或 η 选择，因而这一对照有未见来源意义；但状态仍是 FRONT_ID 轨迹的同状态教师标签，不是校正器自身闭环，也不是终图质量。
2. **新 31 源表训练内结果**：分别保存未限幅 FP64、限幅 FP64、已存 FP32 系数在 FP64 仿射算术中的误差。最后一种只是系数转换诊断，不模拟真实部署的 FP32 乘加和 BF16 返回舍入，不能称为“实际 BF16 部署误差”。
3. **固定 η 的 31 折 LOO**：每折从剩余 30 来源重新聚合，λ、RMS 界和系数均仅由该训练折形成，不从全 31 源统计减去留出项。没有候选扫描、最优折挑选或通过阈值。旧八源中某个留出来源仍可能影响过历史 η 选择，因此此 LOO 也不能被包装为整个算法选择流程的完全无泄漏验证。

留一和训练内报告均只作诊断。程序不沿用旧八源的 10%/6-of-8 门，不将其任意外推到 31 源，不把“数值下降”自动转成 D5 GO。

## 4. 执行前硬前置条件

入口 `scripts/fit_d4_u_fixed.py` 要求实际 `data_d4_u/independent_audit.json` 为 PASS，并具备 `ready_for_fitting_data_audit=true`；校验实际 protocol/ledger/status/sampling SHA、24 请求、330 invoked/completed、192 student、138 dense、23 新 moments、旧八源及 31 候选来源。审计须明确实际逐步 Euler、同状态教师、真实锚点、原始位模式、U moments 独立重建、23 个 k=1 完整控制以及唯一 native fallback 的八步/PNG 精确对照均通过。

拟合程序读取该独审的实际 schema，验证其 auditor 源码 SHA、输入 SHA 与冻结源码 SHA。随后再次核对 ledger 中全部 **432 个 raw NPZ/JSON 文件**的实际 SHA/字节与侧车来源、step、protocol、teacher/监督存在性，并核对每份新 moments 绑定的原始侧车 manifest。它不重新调用教师、不替代独立审计，也不把只有 metadata 的验证冒充逐 token 重算；逐 token 重算由独立 D4 审计承担。

每一新旧 moments 都校验 64 通道 FP64 sums、九配对、样本 n 与对应已冻结 plan 的 all-inactive 索引数一致。旧八源文件必须与 D4 protocol 引用及旧 D0 ledger 一致；旧表 artifact 另固定为 `b19b1496697389bb7f85103c140e42bce0947aaf85017e9c1152d06a8e66dbb3`。

还要求独立固定拟合代码审阅 JSON，包含 `ready_for_D4_FIXED_FIT=true`、`d4_audit_sha256` 与 `execution_source_sha256`，后者须绑定新 fitter、本协议、冻结 bounded_fit/moments 源码。缺少真实 D4 数据或 PASS 回执时必须停止；不得预填收据。

```bash
python scripts/fit_d4_u_fixed.py \
  --d4-audit data_d4_u/independent_audit.json \
  --review data/independent_d4_fixed_fit_review.json \
  --preflight-only
```

删去 `--preflight-only` 才会执行已获 readiness 的离线估计。输出目录已存在即拒绝，不自动重试、恢复或覆盖。源文件与证据在结束时再次校验 SHA。

## 5. 输出与部署兼容性

默认新目录 `training_d4_u_fixed/`：

- `preregistration.json`：首次拟合之前冻结来源、η、九配对、各项证据 SHA、诊断范围及无自动后续授权。
- `bounded_U_train31_fixed_eta001.npz`：沿旧 `schema_version=1` 和 `bounded_source_equal_ridge_v1` 的 route_b 结构；alpha/beta `[1,8,8,64]`、coverage/observed/counts `[1,8,8]`，兼容旧 moments NPZ 编码与读取。增加固定估计协议标识，`loo.selected_eta` 仅为旧 schema 兼容字段，明确本轮未进行 selection；`loo.gate=null`。
- `velocity_runtime_table_train31.npz`：取 synthetic layer 0 得 `[8,8,64]`，连同 coverage、模型身份、原 scheduler timesteps、31 training IDs 和主校准 artifact SHA，满足 `velocity_affine_runtime.prepare_velocity_coefficients` 的字段约定。这里只检查 NumPy 结构/序列化；真正 runtime 运行尚未发生。
- `fit_summary.json`：参数数目、限幅计数、逐配对 source/token 覆盖、全部来源误差、旧表在新源上的对照、固定 LOO、CPU 估计耗时及 artifact SHA。
- `status.json` 或首次失败的 `failed.json`：始终保留 `model_calls=0`、`D5_approved=false`、`quality_accepted=false`，失败不删除部分文件。

九配对有 576 个有效 alpha 和 576 个有效 beta，共 1,152 个标量、4,608 字节有效 FP32 参数；完整身份填充表为 32,768 字节 alpha/beta，coverage、计数、元数据与文件封装另计。不能将 NPZ 文件总大小说成仅4,608字节。

## 6. 独立验收建议与后续决定

独立验收应至少：

1. 从 31 个输入重新构造来源等权矩与每配对 31 来源/实际 token 账本，确认 fallback 从未伪造 moments，未混入 Dev/Probe/Test。
2. 用公式或第二实现抽查全部九配对的 a/b、λ、RMS 界、独立 clip 顺序及 FP32 内向舍入；所有未覆盖/同时间/未来位置必须是 identity。
3. 从已存系数独立重算每源训练内误差、旧表→新23误差与源间均值比；固定 η LOO 每折训练 ID 恰为其余30源，并确认 λ/RMS 不读取留出来源。
4. 核对两个 artifact 的位级参数一致、输出 SHA 与冻结协议绑定；runtime table 的 source_sha256 指向主校准表，而非把 metadata 自身当模型身份。
5. 将结果保留为同状态代理，另审实际 BF16 闭环、终图语义和净延迟。D3 F 已有语义失败，F 也不能用作语义真值；训练来源数量扩大并不能直接证明这些错误被消除。

完成上述验收后是否进入 D5，由新的独立决定/预登记控制。当前脚本没有模型加载、推理、数据补采、策略更新或 RL 调用；扩大来源与延长 RL 预算仍是不同实验变量，不能混在一次未受控对照中。
